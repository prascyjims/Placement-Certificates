# Insurance Data Engineering & CI/CD Platform
A small end-to-end insurance data engineering project using SQL, Azure Data Factory, ADLS Gen2, Azure Databricks/PySpark, and Azure DevOps CI/CD.

## Scope
- Ingest insurance data using ADF into ADLS Gen2.
- Transform and validate data using Databricks/PySpark.
- Use Azure DevOps CI/CD to deploy SQL scripts, ADF pipelines, and Databricks notebooks across development and production using environment-specific settings.
- Add validation and monitoring to identify deployment issues and support reliable pipeline execution.

The sample data intentionally contains multiple duplicates, missing values, invalid references, and invalid values.
